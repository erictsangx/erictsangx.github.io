eric-worklog Privacy Policy

Last updated: 2026-11-07

Data eric-worklog accesses

eric-worklog requests the Google Drive scope https://www.googleapis.com/auth/drive.file, which only allows access to files that eric-worklog creates or that the user explicitly opens with it. It does not access any other Google Drive files, Gmail, contacts or profile data beyond the user's email address used for sign-in.

How the data is used

Files are uploaded to and downloaded from the user's own Google Drive solely to archive and restore the user's own work documents. File names and checksums are recorded on the user's private server to track versions.

Storage and security

OAuth tokens are stored encrypted on the user's private server only. Files remain in the user's own Google Drive and on the user's own server. No data is stored on any server operated by anyone else.

Sharing

eric-worklog does not sell, rent, share or transfer user data to any third party, does not use it for advertising, and does not use it to train AI or machine-learning models.

Limited Use

eric-worklog's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Users can revoke eric-worklog's access at any time at https://myaccount.google.com/permissions. Archived files can be deleted directly in Google Drive; the local version records are deleted when the user removes them from the server.
