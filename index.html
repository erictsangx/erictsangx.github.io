eric-worklog

eric-worklog is a personal productivity tool that archives and retrieves my own work documents (Word, Excel, PDF) between my private server and my Google Drive.

What eric-worklog does

  • Uploads older work files from my server to a dedicated folder in my Google Drive to free up disk space.
  • Downloads those files back to the server when I need them again.
  • Only accesses files that eric-worklog itself created (Google Drive drive.file scope). It cannot see any other files in Google Drive.

Who can use it

eric-worklog is used only by its developer for personal work. It is not offered to the public and requires no account on this website.

eric-worklog does not use Google APIs to create, generate or process any AI-generated imagery.
